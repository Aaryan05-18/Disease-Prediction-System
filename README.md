# Disease Prediction System

A Java Swing based Disease Prediction System that predicts possible diseases based on selected symptoms.

## 📌 Project Overview

This is a desktop-based application developed using Java Swing.  
The user selects symptoms such as fever, cough, headache, and fatigue, and the system analyzes the selected symptoms to provide a possible disease prediction.

## 🚀 Features

- Simple and user-friendly GUI
- Symptom-based disease prediction
- Supports multiple symptoms
- Prediction confidence percentage
- Reset option to clear the selected symptoms
- Built using Java Swing

## 🛠️ Technologies Used

- Java
- Java Swing
- AWT
- Object-Oriented Programming
- Probabilistic prediction logic

## 🧠 How It Works

The application takes four symptoms as input:

- Fever
- Cough
- Headache
- Fatigue

The selected symptoms are converted into binary values and compared with predefined symptom patterns. A probability score is calculated for different diseases, and the disease with the highest probability is displayed.

## ▶️ How to Run

1. Install Java JDK on your system.
2. Download or clone this repository.
3. Open `DiseasePredictionGUI.java` in IntelliJ IDEA, Eclipse, or any Java IDE.
4. Compile and run the program.
5. Select the symptoms and click **Predict**.
